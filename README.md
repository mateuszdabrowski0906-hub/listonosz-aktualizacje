# Listonosz — aktualizacje

Tutaj są publikowane instalatory programu **Listonosz** (maile z dokumentami dla klientów biura rachunkowego).

Program sam sprawdza to miejsce i proponuje instalację nowej wersji. Każde wydanie zawiera plik `latest.json`
podpisany cyfrowo przez wydawcę — Listonosz instaluje wyłącznie aktualizacje z poprawnym podpisem.

Najnowszy instalator: zakładka **Releases** → najnowsze wydanie → `Listonosz-Instalator-<wersja>.exe`.
