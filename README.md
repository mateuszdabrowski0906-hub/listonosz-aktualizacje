# Listonosz 1.1.0

Aktualne wydanie programu Listonosz (instalator podzielony na części, łączony automatycznie przez program).

- Automatyczne aktualizacje — program sam pobiera nowe wersje i instaluje je jednym kliknięciem.
- Podpisy ze zdjęciem albo logo: kilka szablonów, podgląd na żywo, wybór podpisu dla klienta.
- Lepszy odczyt przelewów z Optimy: zaliczki PIT-36L (PPL) i przelewy ZUS bez numeru rachunku.
- Rodzaj przelewu rozpoznawany też po słowach w nazwie pliku (np. „PrzelewDochodowy”, „PrzelewZUS”).
- Nazwę przelewu zmienisz jednym kliknięciem na karcie przelewu.
- Sortowanie listy klientów: zaznaczeni najpierw, po nazwie albo po stanie.
